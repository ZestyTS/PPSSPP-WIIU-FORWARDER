# PPSSPP Wii U Autoboot Runtime

ZestyTS's fork of [NicoAICP/PPSSPP-WIIU-FORWARDER](https://github.com/NicoAICP/PPSSPP-WIIU-FORWARDER),
based on [aliaspider's Wii U port](https://github.com/aliaspider/ppsspp/tree/wiiu).

**Experimental. Tiramisu only. Aroma is not supported by this release branch.**
Game compatibility and performance vary; some titles can hard-freeze the console.

## Use with UInjectForge

Download the runtime ZIP from this fork's Releases. Keep `PPSSPP.rpx`,
`PPSSPP.runtime.json` and `assets/` beside each other, then choose the RPX in
UIF. The runtime ZIP itself is not a WUP installable.
